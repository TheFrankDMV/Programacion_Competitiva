# Programación Competitiva

Repositorio donde guardo mi material de **programación competitiva**, principalmente mis soluciones a problemas y plantillas de uso frecuente.

## 📁 Contenido

### `Soluciones/`

Contiene mis soluciones a problemas de diferentes concursos y plataformas.

Para encontrar un problema específico, se puede utilizar el **buscador de GitHub**. Los archivos siguen ciertas convenciones de nombres para facilitar su búsqueda.

* **Olimpiadas:** los problemas se guardan utilizando su **nombre identificador**. Si el problema no tiene un identificador claro, probablemente se utiliza alguna parte significativa de su nombre. En estos casos, puede ser más sencillo buscar el problema por su fuente.
* **CSES:** los problemas se guardan utilizando su **nombre completo**, sin numeración.
* **ICPC:** los problemas se identifican únicamente con la **letra del problema**, por lo que es recomendable buscarlos por concurso o fuente.
* **Otros concursos:** se intenta utilizar un nombre que permita identificar el problema fácilmente.

Siempre que exista una plataforma donde se pueda **enviar una solución (submit)**, se incluye también el enlace correspondiente, junto con el **nombre completo del problema**.

> **Nota:** Los nombres de los archivos pueden omitir acentos o caracteres especiales para evitar problemas de compatibilidad y facilitar su manejo.

### `Templates/`

Contiene plantillas y código reutilizable para programación competitiva.

Los archivos utilizan **nombres cortos e identificadores**, generalmente relacionados con la estructura de datos, algoritmo o técnica que implementan.

La idea es que esta sección funcione como una colección de herramientas que puedan reutilizarse rápidamente durante una competencia.
